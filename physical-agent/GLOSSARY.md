# Physical Agent

用语音指挥多台个人设备协作完成一件事的系统：云端总控调度，各设备主动连上来接命令。

## Language

### 角色

**总控**:
跑在云服务器上的协调程序，所有设备和语音助手都只跟它通信。
_Avoid_: 服务器、后端、主控

**执行端**:
每台电脑上常驻的程序，连着总控，负责在本机执行命令。
_Avoid_: Device Agent、客户端

**语音助手**:
Agora 上的对话 Agent，是系统里唯一负责理解用户、决定调用哪个工具并开口回答的角色。
_Avoid_: 语音 Agent、主控、主 Agent

**编码子代理**:
在某台电脑上由执行端启动的 Claude Code，负责按提示文件生成代码。
_Avoid_: 子 agent、Agent B

**手表**:
ESP-Mosaico 穿戴设备，只负责听、显示、按键和震动，不负责回答。
_Avoid_: Mosaico 端、穿戴端

**语音页**:
手机上打开的网页，负责语音助手的收音和播放。将由 voicTrl app 取代。
_Avoid_: 手机 App、前端

**voicTrl app**:
手机上的网页 app（PWA），包含通话、任务步骤、设备状态三块；代码在 `C:\maven\voicTrl\frontend`。
_Avoid_: 前端、面板、dashboard

**唤醒器**:
把睡眠中的电脑叫醒的 ESP32 小板，分 LAN 唤醒器（发魔术包）和 USB 唤醒器（USB 远程唤醒）。
_Avoid_: 开机棒、插件

### 动作与数据

**唤醒**:
把电脑从睡眠叫醒。"开机"只指冷启动，本项目不做。
_Avoid_: 开机、启动

**任务**:
用户一句话要完成的整件事，可能跨多台设备、包含多条命令。
_Avoid_: 指令、job

**命令**:
总控发给一台设备的一个动作。
_Avoid_: 步骤、操作

**话语**:
手表或手机转成文字后发给总控的一句用户的话，由总控注入语音助手的对话。用户在语音页里直接对语音助手说的话不算话语。
_Avoid_: 语音指令、transcript（transcript 只指语音助手回答的文字）

**显示**:
总控推给手表的一屏内容，可以附带震动。
_Avoid_: 通知、推送

**成果包**:
编码子代理生成的文件打成的压缩包。
_Avoid_: 结果、输出

**结果确认**:
在用户点名的电脑上打开成果包，等用户说"确认"。
_Avoid_: 展示、验收
